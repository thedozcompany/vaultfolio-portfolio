A travel planning web app that turns rough itineraries into shareable visual trip guides.

Tech Stack Next.js, Supabase, Mapbox, Vercel
Role Co-founder & lead developer
Timeline 6 months
Live Url View Project

Overview

Planning a trip involves too many tabs — Google Maps, Notes, spreadsheets, group chats. Wandr pulls it all into one shareable visual guide.

Key Features

- Drag and drop itinerary builder

- Mapbox-powered route visualisation

- Shareable trip links (no signup required for viewers)

- Collaborative editing for group trips

- Export to PDF

Results

- 800+ trips created in first month

- Featured in The Indie Hackers newsletter

- 3.2k waitlist signups before launch
